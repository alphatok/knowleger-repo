# review/ — 待人类裁决

AI 在整理时，遇到**拿不准的事**就写到这里，**绝不擅自决定**。

典型场景：

- **疑似重复**：新片段可能和已有笔记是同一概念，但不确定 → 列出两篇，请你决定合并还是分开。
- **内容矛盾**：新旧说法冲突 → 并列两种说法 + 来源，请你仲裁。
- **分类存疑**：找不到合适分类 → 建议新增分类，等你确认。
- **事实存疑**：AI 无法核实 → 标注「待验证」，避免污染知识库。

## 处理方式

看完后：直接改 `knowledge/` 或 `meta/taxonomy.md`，然后**删掉本目录里对应的文件**即可。
`kb lint` 与 `kb status` 会提醒这里还有未裁决项。

## 文件命名

`YYYY-MM-DD-<主题>.md`，例如 `2026-10-18-向量数据库是否与嵌入模型重复.md`。
